# Attribution and reuse

The processed observations were obtained from the dataset accompanying Sethi et al. (2023), Nature Ecology & Evolution, DOI [10.1038/s41559-023-02148-z](https://doi.org/10.1038/s41559-023-02148-z). The source data release, *Data associated with sscape-avian-div-generalisability*, is credited to Sarab Singh Sethi (2022) and is [Zenodo 7446640](https://doi.org/10.5281/zenodo.7446640), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The review archive contains derived event tables and experiment manifests. It also contains Adam Ali's analysis results and figures. These data and figures are distributed under CC BY 4.0. The event tables preserve the released feature values and species labels; project event identifiers and pair manifests were added. The primary analysis removes the exact label `NA` and excludes empty bird communities. The sensitivity analysis retains the original labels and all events. This reuse does not imply endorsement by the original authors.

The MIT license in this repository applies to Adam Ali's code. No code from the source authors' repository or code archive is redistributed here. Their GitHub repository informed the presentation of this release: a short README, separate data download and scripts for individual analysis tasks.
